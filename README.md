# Portfolio

This is a personal portfolio website created using HTML, CSS, and JavaScript. It showcases my skills, projects, and contact information.

## Features

- Responsive design using W3.CSS framework.
- Sections for Home, About, Photos, and Contact.
- Interactive elements powered by JavaScript.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Lajja07/portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Open `index.html` in your web browser to view the portfolio.

## Technologies Used

- HTML
- CSS
- JavaScript
- W3.CSS
